# EventForce Management System

## Project Overview

EventForce is a Salesforce-based Event Management System developed to manage events, clients, vendors, venues, and feedback in a centralized platform.

The system uses Salesforce features such as custom objects, relationships, automation, approval processes, security configurations, reports, and dashboards.

## Objectives

* Manage event information in a centralized system
* Maintain Client, Vendor, Venue, and Feedback records
* Automate important event management activities
* Apply validation and approval processes
* Implement Salesforce security features
* Generate reports and dashboards for monitoring

## Salesforce Objects

The project includes the following objects:

* Event
* Client
* Vendor
* Venue
* Feedback
* Event Vendor

## Key Features

* Custom Salesforce Objects and Relationships
* Salesforce Flows
* Validation Rules
* Approval Process
* Profiles and Permission Sets
* Reports and Dashboards
* Event Planner Lightning App
